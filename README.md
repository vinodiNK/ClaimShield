# ClaimShield – AI Insurance Fraud Detection System

### AI-powered insurance claim verification platform designed to detect fraudulent claims using Machine Learning and Natural Language Processing (NLP).

### The system analyzes claim documents, performs anomaly detection on historical claim data and generates a fraud probability score using a custom risk scoring engine. An Explainable AI dashboard is being integrated to ensure transparency in model decision making.

### The backend is built using FastAPI with PostgreSQL for structured data storage and fraud analytics, while the frontend is developed with React.js. The platform is designed with RESTful APIs and deployed on Oracle Cloud Infrastructure (OCI) for scalability and enterprise level reliability.

## Key Features:
### • NLP-based document analysis for claim verification.
### • Fraud probability prediction using ML models.
### • Anomaly detection in claim history.
### • Explainable AI dashboard for transparent decision insights.
### • Cloud deployment on OCI(Oracle Cloud Infrastructure).
